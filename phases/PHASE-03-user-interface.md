# Phase 03 — Views and User Interface

## Objective
Make Employee and Department data usable through Odoo's web interface.

## Learn
- XML structure and data files
- Form and list views
- Search views and filters
- Menus and window actions
- View inheritance and XPath
- Domains and context
- Buttons and object methods
- Basic Odoo UI conventions

## Build
1. Create list and form views for employees.
2. Create list and form views for departments.
3. Add search fields and useful filters.
4. Add menus and window actions.
5. Add status indicators and sensible field grouping.
6. Add a department employee smart button or related action if appropriate.
7. Test create, read, update and delete flows through the UI.

## Acceptance criteria
- Users can navigate to Employees and Departments.
- Records can be created, viewed and edited.
- Search and filters return the expected records.
- Department and manager relationships display correctly.
- XML files load without errors.
