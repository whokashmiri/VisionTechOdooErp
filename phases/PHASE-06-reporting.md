# Phase 06 — Reports and PDF Documents

## Objective
Generate useful printable documents from ERP records.

## Learn
- QWeb templates
- Report actions
- Report paper formats
- Rendering record data in templates
- Access control for reports
- Report testing and layout debugging

## Build
1. Create an employee profile PDF report.
2. Create a department employee listing.
3. Create a leave request summary report.
4. Add company details and clear document formatting.
5. Add report actions to relevant menus or forms.
6. Verify that users only print reports they are authorized to access.

## Acceptance criteria
- Reports render as PDFs without errors.
- Correct employee and department information appears.
- Empty optional values are handled cleanly.
- Page breaks and layout are readable.
- Report access respects security requirements.
