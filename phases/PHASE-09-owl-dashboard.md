# Phase 09 — OWL Frontend and Management Dashboard

## Objective
Build a custom management dashboard using Odoo's JavaScript framework.

## Learn
- Modern JavaScript and modules
- OWL components
- Component lifecycle
- Props and reactive state
- Hooks
- Services
- Registries
- Client actions
- XML templates
- Asset bundles
- Backend data access patterns
- Basic charts and data visualization

## Build
1. Create a dashboard client action.
2. Register the action correctly.
3. Build an OWL component and template.
4. Display employee and department totals.
5. Display pending leave requests and active projects.
6. Add a stock alert or sales summary when those modules are available.
7. Add loading, empty and error states.
8. Respect user permissions when loading dashboard data.

## Acceptance criteria
- Dashboard opens through an Odoo menu.
- Components render without browser console errors.
- Metrics match the underlying records.
- Loading and empty states are handled.
- Users only see metrics they are authorized to access.
